# InvestIQ moderated usability protocol

Status: **Prepared, not executed. Participant results are not yet claimed.**

Use this kit for five or more moderated sessions only after owner approval. Recruit participants who
can discuss research software without sharing real financial accounts. Do not collect full name,
email, account credentials, real portfolio balances, actual holdings, or other sensitive personal
data. Assign anonymous session IDs and store consent separately.

Files: [participant script](PARTICIPANT_SCRIPT.md), [tasks](TASKS.md),
[observer guide](OBSERVER_GUIDE.md), [results template](RESULTS_TEMPLATE.csv),
[issue log](ISSUE_LOG_TEMPLATE.md), and [synthesis template](SYNTHESIS_TEMPLATE.md).

These empty templates are evidence of a protocol, not evidence of usability outcomes.
