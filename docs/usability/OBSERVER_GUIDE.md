# Observer guide

Record an anonymous session ID, device, viewport, language, task start/end, completion without help,
misclick count, observable confusion, data-source explanation, critical failure, and short verbatim
feedback. Do not infer participant intent; separate observation from interpretation.

Intervene only for safety, a broken environment, or after marking the task incomplete. A critical
failure includes mistaking synthetic history for real data, mistaking an assumption for SEC fact,
interpreting a DCF result as a recommendation/forecast, or being unable to locate source evidence.

After each session, remove accidental PII, link each issue to evidence, and avoid percentages until
the planned participant set is complete. Do not create successful rows for sessions that did not occur.
