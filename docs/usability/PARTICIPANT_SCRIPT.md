# Participant script

Thank you for reviewing InvestIQ. We are testing the product, not you. Please think aloud and say
what you expect before clicking. The session should take about 30 minutes. You may stop at any time.

Do not enter real account information, actual holdings, balances, full name, email, or other sensitive
information. Use only the sample tickers and fictional amounts in the tasks. We will record task
completion, time, misclicks, confusion, source understanding, device/language, and voluntary comments
under an anonymous session ID. Ask for consent before any screen/audio recording.

The facilitator may repeat a task but should not teach the interface until that task ends. Close by
asking: “What felt trustworthy, what felt unclear, and what would you verify before using an output?”
