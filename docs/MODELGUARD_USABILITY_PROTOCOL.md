# ModelGuard usability protocol

Review the public demo at 320 px, desktop width, each text scale (100%, 115%, 130%, 145%), and in
English and Simplified Chinese. Walk through: open Audit, choose the clean sample, choose the error
sample, locate a cell-specific issue, compare two versions, export CSV/JSON/PDF, clear the session,
and confirm that the privacy line remains visible. Repeat with keyboard only and with reduced motion.

Acceptance requires visible focus, labelled file inputs and buttons, no horizontal overflow, a
clear local-processing statement before upload, and no market-data terminology on any active route.
